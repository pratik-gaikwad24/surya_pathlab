# Surya Pathology Lab

Website and social media material for Surya Pathology Laboratory, Moshi & Chikhali (Pune).

## Folders

| Folder | What's inside |
|---|---|
| `suryapathlab_website/` | The 5-page website: Home, About, Services, Gallery, Contact, plus `style.css`, `script.js` and `assets/` |
| `social media/logo/` | Logo files (PNG with transparent background, and SVG) |
| `social media/posters/` | Offer and awareness posters |
| `social media/photos/` | Health camp photos |

The `index.html` in the root only forwards visitors to `suryapathlab_website/`.

## Run the website locally

```bash
cd suryapathlab_website
python -m http.server 8000
```

Then open http://localhost:8000
